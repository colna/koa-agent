## Phase 总结

### Phase 1 · 基础骨架（2026-10-14 完成）

- **产出**：工程脚手架（TS strict NodeNext / biome / vitest / pnpm）→ 配置模块（zod fail-fast）→ Koa 应用骨架（统一错误信封、JSON 请求日志、`GET /health`）→ 入口与优雅退出（`loadDotEnv` 容错、SIGTERM/SIGINT 关停）。
- **测试**：4 个文件 28 passed；真机冒烟 `/health` 200、SIGTERM → exit 0。
- **踩坑**：① Koa 隐式 404 下赋 `ctx.body` 会被拉回 200，需先显式 `ctx.status`；② 手动 `process.emit('SIGTERM')` 不会带信号名参数（测试注入 `exit` 直测）。
- **commit**：81ecdf0 / a20c1ca / dad02a8 / 6c9255c / 0e37bdd + 本收尾 commit。

### Phase 2 · Agent 核心（2026-10-14 完成）

- **产出**：LangChain 依赖（langgraph 1.5.0 / core 1.2.17 / openai 1.6.2）→ FakeChatModel 离线测试基建 → calculator / current_time 工具 → 手写 StateGraph ReAct（ToolNode + toolsCondition + MemorySaver）→ `POST /agent/chat`（ChatOpenAI 工厂，OpenAI 兼容端点）。
- **测试**：8 个文件 69 passed；真机冒烟 /health + 422 信封链路 + SIGTERM。
- **关键实测结论**（已写入技术文档 §5、ADR）：classic `streamMode:"messages"` 对本版本自定义模型只回聚合最终消息；逐 token 需自定义 callback handler（`lc_prefer_chat_model_stream_events` + `content-block-delta`）走 stream-events 协议 —— SSE 实现基础。prebuilt `createReactAgent` 已 deprecated（迁 `langchain` 包），故手写 StateGraph。
- **commit**：4807a5c / 542ddf4 / fc2df1e / cba1e7f + 本收尾 commit。

### Phase 3 · 流式与持久化（2026-10-14 完成）

## Phase 6 · Monorepo 改造（server + web）

目标：仓库改为 **pnpm workspaces**（`apps/server` 迁移现有服务 + `apps/web` 新增 Next.js 可视化）；浏览器 **直连 server（CORS）**，不隔代理层（依据知识库反代缓冲教训 `sitin-koa-fastify-proxy-streaming`）。

| Task | 内容 | 交付物 | 验收 / 测试要点 |
|---|---|---|---|
| T6.1 | 仓储结构改造 | 根 `package.json`（workspace 脚本）/ `pnpm-workspace.yaml` / 根 `biome.json` / `.gitignore`；现有代码 `git mv` → `apps/server/` | server 在新结构下 `lint/typecheck/test/build` 全过；根目录一条命令可跑 |
| T6.2 | server CORS | `src/middleware/cors.ts` + `CORS_ORIGIN` 配置 + 测试 | OPTIONS 预检 204 + 允许头；普通响应带 `Access-Control-Allow-Origin`；未配置时默认放行（开发） |
| T6.3 | web 脚手架 | `apps/web`（Next.js 16 + TS + Tailwind，端口 3001） | `pnpm dev:web` 可访问；typecheck/lint/build 过 |
| T6.4 | 流式聊天界面 | `lib/sse.ts` 解析器（纯函数可单测）+ 聊天页（流式渲染 / 多轮 thread / 刷新回读历史 / 错误态） | 解析器单测全过；双服务联调：提问 → 逐 token 显示 → 刷新后历史仍在 |
| T6.5 | 收尾 | README / docs 00·02 更新（monorepo 结构、双服务启动）+ 联调冒烟 | 根目录 `lint/typecheck/test/build` 全绿；双服务同跑冒烟记录 |

## Phase 7 · SP Agent（signal / 报错分析 / 报表 / 在线分析）

目标：把 social-proxy-agent 扩展为 SP（social-proxy）运维 Agent —— 工具直连 **minerva BFF**（`admin-api-*`），能力对齐 sitin-next `feature/sp` 现有接口（`POST /api/social-proxy/v3/admin/signal/create`、`/api/social-proxy/script/error-logs*`、`/api/sp-online/*`、`/api/social-proxy/v3/dashboard/*`）。环境可配（默认 dev）；**signal 发送需对话内人工确认**（工具级双步 confirm）。

| Task | 内容 | 交付物 | 验收 / 测试要点 |
|---|---|---|---|
| T7.1 | SP 接入层 | `sp/client.ts`（Bearer / 双层解包 / 超时 / 错误归类）+ config（`SP_ADMIN_BASE_URL` / `SP_ADMIN_TOKEN` / `SP_REPORT_DIR`）+ `scripts/make-sp-token.mjs`（自签 JWT） | mock 服务单测：双层解包、外层错误、401 指引、网络错误；自签 token 写入 `.env`（不入仓库） |
| T7.2 | 错误分析与报表 | `sp_query_script_errors`（聚合统计 + 样本）/ `sp_build_error_report`（Markdown 报表）/ `sp_export_script_errors_csv`（落盘 + 下载路由） | 聚合数学正确；导出文件存在、下载路由可用且拒绝路径穿越；报告含分维度表格 |
| T7.3 | 在线分析 | `sp_online_overview`（实时设备 + 历史在线）/ `sp_dashboard_query`（v3 看板枚举） | mock 端到端形状与参数校验 |
| T7.4 | signal 发送 | `sp_send_signal`（confirm 双步；去重 / 未知类型 / 内层失败处理）+ SP 系统提示词 | confirm=false 零请求（断言）；confirm=true 三态解析；真实 dev 联调发审计类 `KEEPALIVE_TICK` |
| T7.5 | Phase 7 收尾 | web 消息 URL 可点击 + README / docs 00·02 更新 + 全量验证 | 根四命令全绿；双服务联调记录；memo 沉淀 |

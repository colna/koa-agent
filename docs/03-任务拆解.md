## Phase 2 · Agent 核心

| Task | 内容 | 交付物 | 验收 / 测试要点 |
|---|---|---|---|
| T2.1 | 依赖与测试基建 | 安装 `@langchain/langgraph` / `core` / `openai`；`src/testing/fake-model.ts` + 自测 | FakeChatModel：脚本化回合（tool_calls → 最终回复）、`_stream` 增量、`bindTools` 记录 |
| T2.2 | 工具集 | `src/agent/tools.ts` + 单测 | calculator：`1+2*3`、括号、小数、负数、除零、非法表达式拒绝；current_time：默认时区、指定时区、非法时区返回错误结果 |

| T2.4 | 同步对话接口 | `src/routes/agent.ts`（`POST /agent/chat`）+ 集成测试 | 200 返回 `{threadId, reply}`；缺 `message` → 422 details；自定义 `threadId` 透传；不传自动生成 |
| T2.5 | Phase 2 收尾 | 进度文档 + Phase 总结 | 全命令过；手工冒烟可选项（真实 key 由用户执行） |

## Phase 3 · 流式与持久化

| Task | 内容 | 交付物 | 验收 / 测试要点 |
|---|---|---|---|
| T3.1 | SSE 流式接口 | `src/sse.ts` + `POST /agent/chat/stream` + 测试 | 帧序：多个 `message.delta` → `message.done`；`done.reply` 与 delta 拼接一致；模型抛错 → `event: error` 且响应结束 |
| T3.2 | SQLite 持久化评估与接入 | 安装 / 评估 `@langchain/langgraph-checkpoint-sqlite`；`src/agent/graph.ts` 支持 `AGENT_SQLITE_PATH` + 测试 | 装得动：写入后新实例可续读同 thread；装不动：记录评估结论并降级（进度文档 ADR） |
| T3.3 | 会话历史接口 | `GET /agent/threads/:threadId` + 集成测试 | 已存在 thread 返回按序 user/assistant 消息；未知 → 404；tool 消息不出现在列表 |
| T3.4 | Phase 3 收尾 | 进度文档 + Phase 总结 | 全命令过 |
